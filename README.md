## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harsuu942/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables (optional):**
   ```bash
   cp .env.example .env.local
   ```
   Add your Web3Forms access key if you'd like silent background email delivery to `harsh942.mi@gmail.com`.

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

5. **Create a production build:**
   ```bash
   npm run build
   npm run start
   ```

---

## 🌐 Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Next.js**.
3. (Optional) Set `NEXT_PUBLIC_WEB3FORMS_KEY` in Environment Variables.
4. Click **Deploy**.
